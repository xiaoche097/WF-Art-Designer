# 智能条纹重构 P0/P1 验证记录

## 真实服装取样

使用两张公开服装照片，对每个取样区域分别分析。像素宽度按源照片坐标换算。

| 样本和区域 | 结果 |
| --- | --- |
| Marinière 衣身，归一化范围 `x=.54 y=.262 w=.16 h=.355` | 两色，方向 −2.20°，周期 42.21 px，深色 13.72 px，浅色 28.49 px |
| 同一张照片的袖子，`x=.24 y=.219 w=.17 h=.063` | 两色，方向 60.52°，周期 48.27 px，深色 15.60 px，浅色 32.66 px |
| 同一张照片的浅色背景 | 方向不明确，返回校准提示 |
| 同一张照片的全图 | 周期不稳定，返回重新取样提示 |
| 折叠海魂衫近照，`x=.35 y=.15 w=.50 h=.67` | 方向不明确，返回校准提示 |

衣身参考宽度采用原始照片的独立截线测量。对 `x=779±2` 的五列求平均，在 `y=260–585` 用 RGB 均值 90 的交点作边缘，取七组深、浅条带宽度中位数。参考值为深色 13.43 px、浅色 28.29 px，本次区域估计的相对误差分别约为 2.2% 和 0.7%。这是一张照片中一个区域的结果，袖子记录只用于核对分区域测量。

照片来源：[Marinière，Inga Munsinger Cotton](https://commons.wikimedia.org/wiki/File:Marini%C3%A8re.jpg)；[Marinière sweater close-up，DimiTalen](https://commons.wikimedia.org/wiki/File:Marini%C3%A8re_sweater_close-up.jpg)。

## 当前交付边界

P0/P1 覆盖选区测量、数值调整、标准无缝纹理和重构指令。程序使用结构张量、FFT 自相关和一维 Gabor 响应估计取样区域方向及周期，在 Lab 中聚类周期相位颜色。局部方向格用于取样诊断。

生成参考图时保持原始图片。100% 的参数恢复可通过纹理预览对比检查。尚未生成服装成片，所以成片宽度精度、蒙版外像素一致性和目标 ΔE00 均待 P2/P3 实测。
